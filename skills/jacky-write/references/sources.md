# 方法来源与复用边界

Jacky Write 不在运行时串联下列 Skills。它吸收可复用的决策原则，并以 Jacky 的当次意图和实际内容数据为最高优先级。

## 来源

- Waza `write`：作者声音优先、材料门禁、少而强的修改、不编一人称经历。
- `dbs-content`：先把事情搞清楚、内容与形式匹配、认知落差、表达效率。未吸收“必须有产品”等特定商业立场。
- `dbs-hook` 与 `jacky-hook`：开头独立成立、话题 + Hook + 可信度、口播友好、正文兑现。未吸收固定生成 10–15 个候选或未核实素材增补。
- [`lieflat-less-ai-tone`](https://github.com/larashero3-dotcom/lieflat-less-ai-tone)（MIT）：风格参考优先、信息守恒、白名单式最小修改。未把其词句特征和统计倍率当成通用语言定律。
- [`guoshen`](https://github.com/huangbai-AI/guoshen)（MIT，外部条款保留原权利）：候选线索不等于裁决、上下文复核、来源日期和未检查项披露。完整视频审核保持为独立能力。

## 维护原则

- 不复制外部 Skill 的整份提示词、词库、案例数字或项目路径。
- 新经验优先并入现有原则，不为每个失败无限追加一条禁令。
- 只有真实使用或数据反馈能把风格假设升级为稳定原则。
- 语言模型、平台规则和当下流行的 AI 痕迹会变，定期用新稿件复验，不把时点观测写成永久禁词。
