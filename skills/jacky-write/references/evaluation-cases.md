# Jacky Write 行为验收用例

## 测试缝隙

只通过公开调用行为验收：给 `$jacky-write` 一段口喷、想法或初稿，检查它返回的成稿。不检查内部阶段名、标题数量、固定措辞或某条规则是否被显式提及。

## 硬门禁

任意一项失败，整篇不通过：

- 不编造数字、经历、平台反馈、用户评价、权威背书或因果。
- 保留用户明确给出的事实、限定词和核心判断。
- Hook 的承诺在正文里得到兑现。
- 不把风格偏好冒充成平台规则，不承诺“保证过审”。
- 不因为“去 AI 味”把有张力的表达改成平庸句。

## 效果评分

通过硬门禁后再评分，满分 100：

| 维度 | 权重 | 可观察标准 |
| --- | ---: | --- |
| Hook 与继续阅读欲望 | 30 | 前 2–3 句建立具体事件、结果、反差、问题或明确判断，不靠虚假悬念 |
| Jacky 相似度 | 25 | 像做过事的创作者在给同行拆解，有个人判断，不像通用说明书 |
| 洞察与获得感 | 25 | 不只讲功能，能提炼出机制、方法或可复用的框架 |
| 节奏与信息密度 | 15 | 每段推进新信息，没有换说法重复，长短句服务口播或阅读 |
| 平台和 CTA 适配 | 5 | 结尾的行动与平台和内容目标一致，不强加关注口号 |

80 分为单篇候选通过线。真正验收是 5 个真实选题的盲测：与旧流程对比，用户至少在 4 组中更偏好 Jacky Write 版本。

## 用例 1：有证据的口喷变短视频稿

### 输入

```text
我想讲一件事。之前那条自动化写作 Skill 有 30 万人看过，但我用了半年，反而决定把它推翻。因为它只是 SOP，每次写完都没有沉淀，下一篇还得从头来。我现在的判断是 Skill 不是护城河，会积累的生产体系才是。写成 90 秒口播稿。
```

### 验收

- 开头利用“30 万人看过”与“亲手推翻”的真实张力。
- 不把稿子只写成对旧 Skill 的抱怨，必须交付“为什么不积累”和“新体系怎样形成飞轮”。
- 不增加未给出的涨粉、收入或转化数据。

## 用例 2：有 AI 味但不能改平

### 输入

```text
帮我改这段：
我感觉自己像个小丑。半个月前我还在教大家用四个工具来回折腾，现在一个新工具把四步全装进一张画布。这不是一次功能升级，而是工作方式的推翻。这不是效率工具，而是创意工作台。
```

### 验收

- 保留“小丑”这个有事件支撑的自嘲。
- 保留最强的一层认知反差，处理重复对举，不是见到“不是…而是…”就全删。
- 修改后的开头仍然有张力，不改成“近期我发现一款效率较高的工具”。

## 用例 3：材料不足

### 输入

```text
写一篇关于 AI 时代个人品牌的长文，要像我，3000 字。
```

### 验收

- 不编造 Jacky 的经历和业务数据。
- 不用重复判断硬凑 3000 字。
- 一次性询问最多 3 个真正影响成稿的问题，或明确提供更短的可用版本。

## 用例 4：不把合规扫描当成文风清洗

### 输入

```text
这是要发小红书的工具教程。保留我对产品的真实判断，同时检查可能影响发布的表达。
```

### 验收

- 只对有上下文依据的风险提出替代方案。
- 不把所有“最”“必”或产品名机械删除。
- 明确这是发布前风险预检，不是过审保证。

## 用例 5：不过度套用历史风格

### 输入

```text
我这次想写一篇安静一点的复盘，不要爆款腔，也不要强行加口号。
```

### 验收

- 当次明确要求高于历史爆款模式。
- 不强行加社会证明、悬念、极端比喻和“我是 Jacky”签名。
- 仍然保留具体经历、明确判断和可执行结论，不写成无立场的流水账。

## 用例 6：清楚但不能像分析报告

### 输入

```text
把这篇第一人称实操长文改成适合小红书的长图文。搜索价值和收藏价值要高，但不要写成洞察报告。
```

### 验收

- 逻辑仍然清楚，核心搜索概念自然出现，可执行信息没有丢。
- 第一人称经历按时间、场景、因果或转折推进，不连续套用“做法 / 工具 / 边界”等同构模块。
- 小标题和清单只承担导航或照做功能，不把每段切成对称卡片；真实存在多个步骤、检查项或工具时，仍使用编号提高可读性。
- 去掉规整感后仍有明确判断和收藏价值，不退化成散乱流水账。
- 如果任务是润色排版，不把原文的复数原则压成新限制，也不删掉主要做法来换取更短篇幅。
