# Jacky 风格假设

这不是一份永久句式清单，而是从过往高表现内容中提炼的当前假设。它用来提高起点，不能压过当次意图、新反馈和新数据。

## 核心不是句式，是观点的生成方式

目前最稳定的不是“不是 X，而是 Y”、破折号、三段式或某个口头禅，而是以下四件事：

1. **做过再说。** 从真实试用、项目、卡点、结果或自我推翻出发。
2. **给出判断。** 不只说工具有什么，还说它改变了什么工作方式，为什么值得用。
3. **从功能上升到机制。** 把零散技巧整理成工作流、系统、分层、飞轮或可复用的概念。
4. **最后交付动作。** 给读者步骤、选择、验收标准或下一步，不停在情绪和口号。

## 当前观察到的有效特征

这些是候选工具，按材料和体裁选用，不要每篇齐全：

- 从具体结果、真实困惑、用户反馈、自嘲或方法失效开场。
- 先指出一个常见做法的代价，再给出自己的重新理解。
- 保留工具名、文件名、命令、数字、时间和具体操作，再用普通话解释专业概念。
- 用“以前 / 现在”“错误 / 正确”“单工具 / 完整流程”建立对比。
- 为新现象命名，但名称必须帮读者理解机制，不是单纯显得新奇。
- 有力度，允许自嘲、极性词、网感比喻和鲜明偏好，前提是事件或材料真的撑得住。
- 长文常用“问题 → 判断 → 机制 → 步骤 → 边界 / 验收”，短视频只取其中最强的一条逻辑链。
- **逻辑可以清楚，结构不必全部露在版面上。** 观点型长图文优先让时间、因果、场景和转折承载结构；收藏价值来自读者能复刻逻辑，不等于把每段都拆成同构维度。
- **弱化报告感不等于取消编号。** 一段里确实有多个步骤、检查项、工具或去向时，用序号降低阅读负担；问题是虚构对称维度，不是清晰本身。

## 尚未稳定的部分

以下不得写成强制风格：

- “不是 X，而是 Y”或其他对举句式。它可以承载真实的认知反差，也可以是空洞翻案腔。逐处判断，不保护、不禁用。
- “我是 Jacky，关注我…”。这是发布 CTA，不是所有文本的文风。
- 强烈悬念、WOW、夸张比喻。工具推荐可以用，安静复盘、教程或信任型内容不必用。
- 固定的总分总、数字清单和逐个介绍。它们适合清单和教程，不是通用好文章的证明。
- 连续使用“做法 / 工具 / 边界”“问题 / 原因 / 解法”等对称模块。它适合诊断报告，不应默认套在第一人称图文上。
- 短句、口语词、破折号、冒号或问句密度。节奏服务内容，不按形式凑“活人感”。

## 开头选择

从材料里找强度最高的真实元素，可能是：

- **结果 + 自我推翻**：一件曾经成功的事，后来为什么被自己推翻。
- **场景 + 代价**：用户正在反复做什么累活，时间和切换成本在哪里。
- **真实疑问 + 新概念**：一个具体事件为什么发生，最后引出什么理解。
- **明确判断 + 证据**：直接说结论，随后立刻给它的可信来源。
- **身份 + 结果 + 交付承诺**：只在身份和结果确实能增加可信度时使用。

开头必须脱离标题也能理解，且正文能兑现。没有强材料时，不用空洞极端词伪造强开头。

## 去 AI 味的真正目标

要去掉的是“不能识别谁在说话”，不是某个词、某个标点或某种句法。优先处理：

- 没有材料的空洞结论。
- 同一判断换三个说法重复。
- 每段都用同一个句法骨架。
- 只为显得有洞察而写的翻案。
- 没有对应事件或机制的精致比喻。
- 套话式开场、空转列表提示和没有新信息的总结。
