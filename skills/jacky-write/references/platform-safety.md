# 发布前文本门禁

这一层是风险预检，不是平台内部审核，不承诺过审、流量或账号安全。平台规则会变，高风险场景应核对当期官方条款。

## 什么时候检查

- 用户明确说要发小红书、抖音、B 站、视频号或其他平台。
- 用户要求“查违禁词”“发布前审一遍”。
- 文本涉及绝对化承诺、收益、功效、医疗健康、投资理财、资质、导流、商业推广或使用他人版权素材。

## 怎么检查

逐处区分文本事实、候选风险、上下文例外、可用改法和剩余不确定性。词语命中本身不是裁决。否定、引用、科普、反诈、普通工具名、代码和平台官方组件不得机械判定。

只有确定不改变意思的替换才能直接进入成稿。改动会削弱核心判断、数据或产品事实时，保留原文并单独标注风险。来源、日期或适用场景无法确认时，明确说“需复核”。

## 文本与成片的边界

Jacky Write 只对当前文本负责。标题、封面、图片、二维码、水印、账号认证、发布设置和画面闪现内容，没有实际证据就标为未检查。

用户提供完整视频并要求平台发布预检时，应交给独立的 `guoshen` 类视频审核流程，联合检查语音、字幕、画面和动态平台规则。不在写作 Skill 里伪装成已检查完整成片。
